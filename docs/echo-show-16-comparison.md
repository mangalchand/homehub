# FamilyHub vs. Amazon Echo Show 16 (announced 28 Oct 2026)

Sources: https://www.aboutamazon.com/news/devices/echo-show-16-smart-display and The Verge hands-on (28 Oct 2026). Price $499.99 (Nanomatte $569.99), preorder discount $100.

| Echo Show 16 capability | FamilyHub today |
|---|---|
| Family Organizer: colour-coded family calendar | Yes: shared calendars, per-member colours, legends across the top on tablets |
| Family Organizer: tasks / to-dos assigned and tracked | Yes: tasks, recurring chores, rotation, approvals, points |
| Family Organizer: meal planning dashboard | **New:** weekly Meal plan page (breakfast, lunch, dinner, snack) |
| Cooking Library (recipes) | Not yet (database model ready) |
| Photos screen style / digital frame | Yes: family photo slideshow and idle screensaver |
| Smart Home dashboard, Alexa Home Map | Needs Home Assistant link (see home-controls.md); devices will be grouped by area |
| Always-on screen styles | Yes on paired displays: dashboard, idle photo mode, keep-awake |
| Favourites bar | Partly: dashboard layout and mobile quick nav |
| Alexa+ voice | FamilyHub Alexa skill ("Alexa, ask family hub...") plus on-tablet voice commands |
| Fire TV / streaming | Not applicable |
| Doorbell / who is at the door | Via Ring/Blink/Eufy once Home Assistant is linked |
| Extra in FamilyHub | SOS with live location, rewards with pictures, member photos, daily 8:30 PM summary, spoken announcements, multi-home access, WhatsApp call link |
